# Code of Conduct

This project is developed for professional security engineering and authorized assessment.

Contributors are expected to:

- document security-impacting changes;
- preserve scope and authorization safeguards;
- avoid adding telemetry or credential collection without explicit product requirements;
- respect upstream project licenses;
- avoid committing customer data, credentials, captures, malware samples, or other sensitive artifacts;
- include tests for security-sensitive behavior where practical.
