# Security Policy

This platform is intended for authorized security assessment, penetration testing, incident response, digital forensics, and security engineering.

## Safe use

Only use the platform against systems, networks, wireless environments, applications, credentials, or data for which the operator has explicit authorization.

The platform includes scope enforcement, confirmation gates, and audit logging, but those controls do not replace organizational authorization or applicable law.

## Reporting a vulnerability

Do not publish credentials, exploit proof-of-concept material containing live targets, or sensitive customer evidence in a public issue.

For this repository, report security issues privately through the repository's configured GitHub security reporting mechanism when available.
